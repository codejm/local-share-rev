# Local Share

`Local Share` 是一个面向局域网协作的桌面应用。主机在本机启动服务后，会自动生成可分享链接和二维码；同一网络下的其他人直接用浏览器打开链接，就能进入同一个无限画布，实时协作编辑或实时演示文本、图片和视频内容。

## 软件特点

- 局域网即时协作：桌面端启动后自动暴露局域网地址，浏览器访问即可加入项目
- 无限画布：支持拖动画布、缩放视图、重置居中
- 多媒体内容：支持文本、图片、视频三类元素
- 便捷导入：支持粘贴、拖拽上传、右键上传
- 实时同步：元素新增、移动、编辑、删除会通过 WebSocket 实时广播
- 演示模式：主持人可开启演示，其他人进入只读跟随状态
- 分享能力：可复制项目链接，也可直接扫码加入
- 主持人权限：只有主机侧主持人可以删除项目和元素
- 本地存储：项目数据保存在本机 SQLite，上传文件保存在本地目录
- 发布更新提示：桌面控制面板会检查 GitHub Releases 的新版本

## 使用场景

- 团队现场评审、脑暴记录
- 教学演示、投屏讲解
- 局域网内快速共享图片、视频和文案素材
- 小型工作坊中的临时协作白板

## 安装

### 方式一：从 GitHub Releases 下载

进入仓库的 `Releases` 页面，下载与你系统对应的安装包或压缩包。

说明：

- 只有发起共享的主机需要安装桌面应用
- 协作者通常不需要安装软件，只需通过浏览器访问主机分享的链接

- macOS：优先下载 `.dmg` 或发布页提供的 macOS 安装包
- Windows：下载 `.msi` 或发布页提供的 Windows 安装包
- Linux：下载 `.AppImage`、`.deb` 或发布页提供的 Linux 包

### macOS 首次打开说明

当前 macOS 安装包未做 Apple 公证时，系统第一次打开可能会提示“已损坏”或“请移到废纸篓/垃圾桶”，这通常是系统安全拦截，不代表应用本身真的损坏。

处理方式：

1. 先双击打开一次，等系统弹出拦截提示后关闭。
2. 打开 `系统设置 -> 隐私与安全性`。
3. 在安全区域找到 `仍要打开`。
4. 点击 `仍要打开`，再次确认后重新启动应用。

如果你的系统版本里显示为“安全性”而不是“隐私与安全性”，按用户描述可理解为：

`设置 / 安全性 / 仍要打开`

## 快速开始

### 主机端

1. 启动 `Local Share`。
2. 应用会自动启动本地服务，并显示当前访问地址与二维码。
3. 如有需要，可以在桌面控制面板里修改：
   - 存储目录
   - 服务端口
4. 点击 `复制` 或 `打开`，把链接发给同局域网的协作者。

### 协作者

1. 与主机处于同一局域网。
2. 用浏览器打开主机分享的链接，或直接扫码。
3. 输入昵称后进入项目列表。
4. 打开目标项目后即可开始协作。

## 基本使用

### 新建项目

进入项目列表后点击 `New Project` 创建协作项目。

### 添加内容

- 文本：直接粘贴文本，或右键后选择“粘贴”
- 图片：粘贴图片、拖拽图片文件到画布，或右键上传
- 视频：拖拽视频文件到画布，或右键上传

支持格式：

- 图片：`jpg` `png` `gif` `webp`
- 视频：`mp4` `webm` `mov`

大小限制：

- 图片最大 `10MB`
- 视频最大 `100MB`

### 画布操作

- 拖动画布空白区域进行平移
- 鼠标滚轮缩放视图
- 点击元素选中，拖动元素调整位置
- 使用“居中”按钮快速回到内容中心
- 右键元素可执行复制文本、另存原图、复制视频链接等操作

### 演示模式

主持人可以开启 `演示` 模式：

- 主持人的画布位置、聚焦状态会同步给其他人
- 其他协作者进入锁定状态，只跟随观看，不可修改内容
- 适合讲解、投屏、评审场景

### 分享与权限

- 每个项目都可以单独生成分享链接和二维码
- 首个主机用户拥有主持人权限
- 只有主持人可以删除项目和删除画布元素

## 存储与数据

- 项目元数据保存在本机 `SQLite`
- 上传文件保存在本机配置的共享目录
- 修改存储目录时，应用会执行资源迁移，并显示迁移进度

这意味着 `Local Share` 默认更适合作为同一台主机发起的局域网协作工具，而不是公有云在线服务。

## 技术栈

- 桌面端：Tauri 2
- 前端：React + Vite
- 画布渲染：React Konva / Konva
- 后端：Rust + Axum
- 实时通信：WebSocket
- 数据库：SQLite
